Interaction Tools Reference

NameIconDescription
ButtonInteractive element that triggers actions when tapped or clicked
CanvasDrawing area that allows free-form content creation and manipulation
DragEnables objects to be moved around the screen with touch/mouse input
ParallaxCreates depth illusion by moving layers at different speeds during scrolling
PinchAllows scaling objects larger or smaller using two-finger pinch gestures
ScrollCreates scrollable content areas that extend beyond the visible screen
ShakeDetects device shaking motion to trigger interactions
SpinEnables rotation of objects through circular finger/mouse movements
SwipeDetects directional swipe gestures to navigate or trigger actions
