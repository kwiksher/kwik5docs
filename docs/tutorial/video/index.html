Vorbis(ヴォルビス)

FeatureMP4OGV (Theora)
Audio EncodingAAC - excellent qualityVorbis - royalty-free
CompatibilityWidely supportedLimited support
LicensingPatented, may require feesOpen-source, royalty-free
Audio CompressionHigh efficiency, great fidelityGood quality, slightly less efficient
ApplicationsOffline/online playback, streamingOpen-source and web environments

The costs for AAC licensing are structured based on volume, and fees decrease as the number of units increases. Here’s a quick overview2:

  • For the first 1 to 500,000 units, the fee is $0.98 per unit.

  • For 500,001 to 1,000,000 units, it’s $0.78 per unit.

  • For 1,000,001 to 2,000,000 units, the fee is $0.68 per unit.

  • For 2,000,001 to 5,000,000 units, the cost drops to $0.45 per unit.

    As you produce even more, the fees can go as low as $0.10 per unit for very large volumes (75,000,001 or more units).

Page2 - media play video

External code is set to playBtn on page2. No layer relacment is used.

  • code > External Code.

    • Now set the following code - media_playvideo.lua

media_playvideo.lua

local onComplete = function( event )
   print( "video session ended" )
end

local showControls = true

media.playVideo(
    "http://kwiksher.com/tutorials/Video/kwikplanet.mp4",
	media.RemoteSource, showControls, onComplete )

if you like to play the video included in assets/videos/ folder, please use this one

local onComplete = function( event )
   print( "video session ended" )
end

local showControls = true

media.playVideo( "videos/kwikplanet.mp4", showControls, onComplete )
