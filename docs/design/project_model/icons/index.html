Icons Launch/Splash screens

https://forums.solar2d.com/t/new-icon-size-for-ios/354492

  • 114x114

iOS loads Apple’s launch images of LaunchScreen.storyboardc made by Xcode. You can create it with Xcode.

  • On Android:

    1. Start App
    2. Show the default splash screen
    3. App’s first screen shows.

  • On iOS:

    1. Start App
    2. Show Apple’s launch images
    3. Show the default splash screen
    4. App’s first screen shows.
