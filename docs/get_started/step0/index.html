Installation

Kwik exporter

  1. Download and unzip

    https://github.com/kwiksher/kwik5tmplt/releases/

    • kwik5_project_yyyymmdd-hhmm.zip

  2. Click UXP > com.kwiksher.kwik5.dev-ps_PS.ccx

  3. Dialog appears, slect Install and Yes

    • select Yes

  4. Open Photoshop, and you find Kwik Exporter in Plugin menu

  5. From Kwik Exporter Panel > Settings

    • click Select Folder, and speficy a kwik5 project folder.

  6. back to Menu, and click Open

    • click a .psd in the list, it will open the document

    there is one caveat here because of Photshop bug. We need to make it sure Quick Export As PNG works or not before using Kwik exporter.

    • Please select one layer, and right click with mouse to show the context menu to select Quick Export As PNG

    • just test whether Quick Export As PNG works or not. If not work, restart Photoshop!

  7. click Select Book

    make sure the correct path to book foler is dislayed or not. If not, checkbox Reset and click again Select Book

  8. Select checkbox all in Publish section

  9. Then you can click Publish button

Solar2D

you can click Load Simulator button in kwik editor to load the generated code in Solar2D folder to Solar2D simulator.

Load Simulator is only supported in Mac, so for Windows Show Folder then you can click startSolar2D.bat by mouse
